# SIH26008: Intelligent Conveyor Belt Health Monitoring System

## Overview
SIH26008 is an intelligent conveyor belt health and splice health monitoring system designed for real-time telemetry processing, predictive maintenance, and anomaly detection.

## Current Development Stage
- **Stage**: Step 1 - Clean Foundation & Synthetic Sensor Simulator
- **Status**: Hardware (ESP32) is currently simulated using a Python-based synthetic sensor generator outputting normal operating telemetry.

## Running the Simulator

Ensure you have Python 3.8+ installed.

Run the simulator directly using Python:

```bash
python simulator/sensor_simulator.py
```

Press `Ctrl+C` in the terminal to stop the simulator cleanly.
